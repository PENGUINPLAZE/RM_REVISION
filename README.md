# RM Revise

A revision website for **Cambridge IGCSE Design & Technology 0445** (Paper 1 Product Design and Paper 3 Resistant Materials), made by **Alexey Lykosov**, IGCSE Year 11 student at Garden International School.

## What's inside
- **Learning path:** 71 short lessons in syllabus order, with progress ticks
- **All topics:** every syllabus point (1.1–2.21) and the 281 things you need to know under them
- **3D workshop:** 68 tools and machines you can rotate and use, plus joints and fittings
- Labs: screw builder, vernier, projection, sketching, tempering colours, process stepper
- Quizzes, flashcards, written questions with mark schemes, cheat sheets, Exam Success Kit
- Coins, shop, leaderboard with friend cards, pre-mock challenge
- Teacher tools: signed class-update links for announcements, goals, questions and events

## Privacy
Everything is saved in the visitor's own browser. There is no server, database, sign-in, cookies or tracking. Progress moves between devices with a personal sync link. See the Privacy page on the site.

## Run it
It's a static site, so open `index.html` or host the folder anywhere (GitHub Pages, Vercel, Netlify).
For GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
Live address once Pages is on: **https://penguinplaze.github.io/RM_REVISION/**. `SETUP.md` covers admin keys.
